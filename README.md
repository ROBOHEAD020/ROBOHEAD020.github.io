# Homepage source and preview / 主页源码与预览

## Status / 当前状态

This is an AI-created static starter, not a completed personal introduction or a published website. Replace every bracketed placeholder in `index.html` with information you are willing to make public. / 这是 AI 创建的静态起始框架，不是已完成的个人介绍或已发布网站。请将 `index.html` 中全部方括号占位内容替换为你愿意公开的信息。

## Files / 文件

- `index.html`: homepage with embedded CSS. / 主页及内嵌 CSS。
- `README.md`: preview and publication instructions. / 预览及发布说明。

No external assets, package dependencies, dependency manifest, or lockfile are needed for this starter. If you add a build tool or dependencies later, submit its manifest and existing lockfile, plus any needed assets. Do not submit installed dependencies or caches. / 此框架不依赖外部素材、软件包、依赖清单或锁文件。如果之后添加构建工具或依赖，请提交相应依赖清单、已有锁文件及必要素材，不要提交安装后的依赖或缓存。

## Local preview / 本地预览

Open `index.html` in a browser on your device. No installation or build command is required. Check both a narrow and wide window. Local preview does not count as verifying the live website. / 在本人设备上用浏览器打开 `index.html`，无需安装或构建。检查窄窗口和宽窗口显示效果。本地预览不等于线上网站验收。

## Publish / 发布

1. Create or use a repository named `<your-username>.github.io`, separate from the private Git practice repository. GitHub Free requires a public repository for this homepage. / 创建或使用 `<你的用户名>.github.io` 仓库，与私有 Git 练习仓库分开；GitHub Free 的此类主页仓库须公开。
2. Put the contents of this folder at the repository root so that `index.html` is at the root. Do not upload the enclosing `homework/` directory or the private report. / 将本文件夹内的内容放到仓库根目录，确保 `index.html` 位于根目录。不要上传外层 `homework/` 目录或私密报告。
3. Follow the official [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart) to configure Pages for the branch and root directory you actually use. / 按官方快速入门配置 Pages，选择实际使用的分支和根目录。
4. After deployment, personally open `https://<your-username>.github.io/`. Write your own observations and any actual blocker in the private report (NO AI). / 部署后本人打开线上地址，在私密报告中独立填写观察结果及实际阻碍（禁止使用 AI）。

Handle login and authorization yourself. Do not share passwords, codes, or tokens with AI. Keep your student ID, report, secrets, and private details out of the public repository and site. / 登录与授权由本人处理，不向 AI 提供密码、验证码或令牌。公开仓库和页面中不要出现学号、报告、密钥或私人信息。
